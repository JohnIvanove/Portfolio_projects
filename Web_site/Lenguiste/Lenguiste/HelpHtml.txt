В HTML є кілька інших семантичних тегів, подібних до `<header>` і `<footer>`, які допомагають структурувати ваш контент і надають більше сенсу та значущості вашій розмітці. Ось деякі з них:

### Семантичні HTML теги:
1. `<header>`: Використовується для визначення заголовкової частини документа або розділу. Зазвичай містить логотип, навігаційні елементи, назву документа.
2. `<footer>`: Використовується для визначення нижньої частини документа або розділу. Зазвичай містить контактну інформацію, авторські права, посилання на політику конфіденційності.
3. `<nav>`: Використовується для визначення блоку навігації. Містить посилання на інші сторінки або розділи сайту.
4. `<main>`: Використовується для визначення основного контенту документа. Основний контент є унікальним для кожної сторінки та повинен бути основним об'єктом уваги.
5. `<section>`: Використовується для визначення розділів в документі. Розділи зазвичай мають заголовок і групують пов'язані між собою елементи контенту.
6. `<article>`: Використовується для визначення самостійного блоку контенту, такого як стаття, блог-пост або коментар.
7. `<aside>`: Використовується для визначення додаткового контенту, який розташований збоку від основного контенту. Може містити інформацію, пов'язану з основним контентом, таку як бокові панелі, цитати або довідкові матеріали.
8. `<header>`: Використовується для визначення заголовкової частини документа або розділу. Зазвичай містить логотип, навігаційні елементи, назву документа.
9. `<footer>`: Використовується для визначення нижньої частини документа або розділу. Зазвичай містить контактну інформацію, авторські права, посилання на політику конфіденційності.

### Приклад використання:
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Example</title>
</head>
<body>
    <header>
        <h1>Мій Веб-Сайт</h1>
        <nav>
            <ul>
                <li><a href="/">Головна</a></li>
                <li><a href="/about">Про нас</a></li>
                <li><a href="/contact">Контакти</a></li>
            </ul>
        </nav>
    </header>
    
    <main>
        <section>
            <h2>Розділ 1</h2>
            <p>Це перший розділ контенту.</p>
        </section>
        
        <article>
            <h2>Стаття</h2>
            <p>Це окрема стаття з унікальним контентом.</p>
        </article>
        
        <aside>
            <h3>Бокова Панель</h3>
            <p>Це додатковий контент, пов'язаний з основним.</p>
        </aside>
    </main>
    
    <footer>
        <p>&copy; 2025 Мій Веб-Сайт</p>
    </footer>
</body>
</html>
```

### Інші семантичні теги:
- `<figure>` та `<figcaption>`: Використовуються для включення медіа-контенту та підписів до нього.
- `<details>` та `<summary>`: Використовуються для включення розкриваємого контенту.

Ці семантичні теги допомагають покращити структуру та доступність вашого веб-сайту, роблячи його зрозумілішим як для користувачів, так і для пошукових систем. Якщо у вас є ще питання або потрібна допомога, дайте знати! 🚀

1. **Імпортування бібліотек:**
   ```python
   from flask import Flask, request, redirect, url_for, flash
   from flask_login import login_required
   import smtplib
   from email.mime.multipart import MIMEMultipart
   from email.mime.text import MIMEText
   ```
   Ми імпортуємо необхідні бібліотеки, такі як Flask для створення веб-додатка, flask_login для аутентифікації користувачів, smtplib для відправки електронних листів та бібліотеки для створення форматованих електронних листів.

2. **Ініціалізація додатка:**
   ```python
   app = Flask(__name__)
   ```
   Це створює екземпляр нашого додатка Flask.

3. **Маршрут для обробки форми:**
   ```python
   @app.route("/function2", methods=["POST"])
   @login_required
   def function2():
   ```
   Цей маршрут обробляє HTTP POST запити на адресу "/function2". Функція `login_required` гарантує, що лише авторизовані користувачі можуть надіслати форму.

4. **Отримання даних з форми:**
   ```python
   name = request.form.get('name')
   sender_email = request.form.get('email')
   message = request.form.get('message')
   app.logger.info("Form data received: Name=%s, Email=%s, Message=%s", name, sender_email, message)
   ```
   Ми отримуємо дані, які користувач ввів у форму, та логуємо їх для подальшого аналізу.

5. **Налаштування деталей для відправки електронного листа:**
   ```python
   receiver_email = "nazzych@gmail.com"
   your_email = "your_email@gmail.com"
   your_password = "your_email_password"
   ```
   Вказуємо отримувача (вашу електронну адресу), а також дані для входу в аккаунт відправника (змінні `your_email` та `your_password` повинні бути замінені на ваші реальні дані).

6. **Створення повідомлення:**
   ```python
   msg = MIMEMultipart()
   msg['From'] = sender_email
   msg['To'] = receiver_email
   msg['Subject'] = "Contact Form Submission"
   body = f"Name: {name}\nEmail: {sender_email}\nMessage: {message}"
   msg.attach(MIMEText(body, 'plain'))
   ```
   Створюємо об'єкт повідомлення, заповнюємо його даними з форми та вказуємо заголовки (From, To, Subject).

7. **Відправка електронного листа:**
   ```python
   try:
       server = smtplib.SMTP('smtp.gmail.com', 587)
       server.starttls()
       server.login(your_email, your_password)
       app.logger.info("SMTP server login successful")
       server.send_message(msg)
       server.quit()
       app.logger.info("Email sent successfully")
       flash("Email sent successfully!", "success")
   except Exception as e:
       app.logger.error("Failed to send email. Error: %s", e)
       flash(f"Failed to send email. Error: {e}", "danger")
   ```
   Створюємо з'єднання з SMTP сервером, входимо в аккаунт, відправляємо повідомлення і закриваємо з'єднання. Якщо виникає помилка, ми її логуємо і показуємо повідомлення користувачу.

8. **Перенаправлення користувача:**
   ```python
   return redirect(url_for('home'))
   ```
   Після відправки форми ми перенаправляємо користувача на домашню сторінку.

9. **Запуск додатка:**
   ```python
   if __name__ == "__main__":
       app.secret_key = 'your_secret_key'
       app.run(debug=True)
   ```
   Цей блок коду запускає додаток Flask у режимі налагодження (debug).

Таким чином, цей код обробляє дані з форми, надсилає електронний лист з використанням SMTP сервера Gmail, і логує всі кроки для діагностики можливих проблем. Якщо у вас є додаткові питання або виникають проблеми, будь ласка, дайте знати.
