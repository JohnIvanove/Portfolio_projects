### Завдання: Створення Додатку для Вивчення Мов
#### Огляд
У цьому завданні вам потрібно створити додаток для вивчення мов, який допоможе користувачам вивчати мови. Додаток дозволить користувачам створювати колоди флеш-карток, кожна з яких міститиме слово англійською та його переклад українською, а також підказку для кращого запам'ятовування.

Ви створите три моделі: **User** (Користувач), **Deck** (Колода) та **Card** (Картка), а також функції для підтримки базової CRUD-функціональності (Створення, Читання, Оновлення, Видалення).

### Моделі
#### User (Користувач)
- **id** (ціле число)
- **name** (рядок)
- **email** (рядок)
- **password** (рядок)

#### Deck (Колода)
- **id** (ціле число)
- **name** (рядок)
- **user_id** (ціле число)

#### Card (Картка)
- **id** (ціле число)
- **user_id** (ціле число)
- **word** (рядок, англійською)
- **translation** (рядок, українською)
- **tip** (рядок)

### Функції
#### User (Користувач)
- **user_create(name, email, password) -> User**: Створює нового користувача та повертає об'єкт користувача.
- **user_get_by_id(user_id) -> User**: Знаходить користувача за його ID та повертає об'єкт користувача.
- **user_update_name(user_id, name) -> User**: Оновлює ім'я користувача та повертає об'єкт користувача.
- **user_change_password(user_id, old_password, new_password) -> bool**: Змінює пароль користувача та повертає логічне значення, яке вказує на успіх або невдачу операції.
- **user_delete_by_id(user_id) -> bool**: Видаляє користувача за його ID та повертає логічне значення, яке вказує на успіх або невдачу операції.

#### Deck (Колода)
- **deck_create(name, user_id) -> Deck**: Створює нову колоду, яка належить користувачу, та повертає об'єкт колоди.
- **deck_get_by_id(deck_id) -> Deck**: Знаходить колоду за її ID та повертає об'єкт колоди.
- **deck_update(deck_id, name) -> Deck**: Оновлює ім'я колоди та повертає об'єкт колоди.
- **deck_delete_by_id(deck_id) -> bool**: Видаляє колоду за її ID та повертає логічне значення, яке вказує на успіх або невдачу операції.

#### Card (Картка)
- **card_create(user_id, word, translation, tip) -> Card**: Створює нову флеш-картку та повертає об'єкт картки.
- **card_get_by_id(card_id) -> Card**: Знаходить флеш-картку за її ID та повертає об'єкт картки.
- **card_filter(sub_word) -> tuple[Card]**: Знаходить всі флеш-картки, які містять підрядок в полі `word`, `translation` або `tip`, та повертає кортеж об'єктів карток.
- **card_update(card_id, word=None, translation=None, tip=None) -> Card**: Оновлює поля флеш-картки та повертає об'єкт картки.
- **card_delete_by_id(card_id) -> bool**: Видаляє флеш-картку за її ID та повертає логічне значення, яке вказує на успіх або невдачу операції.

### Інструкції
1. Налаштуйте новий Python проект і створіть файл `linguist.py`.
2. Визначте моделі **User**, **Deck** та **Card** з відповідними полями.
3. Реалізуйте кожну з функцій, перелічених у розділі Функцій цього завдання. Використовуйте рядкові коментарі Python (docstrings) для документування кожної функції.
4. Протестуйте ваші функції, створивши окремий скрипт, який створює користувачів, колоди та флеш-картки, і виконує різні CRUD-операції. Використовуйте оператор `assert` Python для перевірки, що очікувані значення повертаються кожною функцією.
5. Зробіть необхідні корективи у вашій реалізації на основі результатів тестування.
